# Security Policy

## Supported Versions

We actively maintain and support the latest version of **AntiWatermark**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data issue, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Instead, use GitHub's private vulnerability reporting under the **Security** tab of this repository.
3. Please include detailed steps to reproduce the issue.

We will review and respond to reports promptly.
